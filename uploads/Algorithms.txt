1. 3D RESNET-50 (VOLUMETRIC STRUCTURAL MRI ENCODER)
--------------------------------------------------------------------------------
• WHERE USED: neurosense/models/mri_encoder.py
• LOGIC: Extends 2D convolutions to 3D spatial tensors (D×H×W). Residual bottleneck
  blocks preserve volumetric depth and anatomical symmetries (caudate/putamen).

• CODE SNIPPET:
```python
class Bottleneck3D(nn.Module):
    def __init__(self, in_ch, out_ch, stride=1):
        super().__init__()
        mid_ch = out_ch // 4
        self.conv1 = nn.Conv3d(in_ch, mid_ch, kernel_size=1, bias=False)
        self.conv2 = nn.Conv3d(mid_ch, mid_ch, kernel_size=3, stride=stride, padding=1, bias=False)
        self.conv3 = nn.Conv3d(mid_ch, out_ch, kernel_size=1, bias=False)
        self.shortcut = nn.Sequential() if in_ch == out_ch else nn.Conv3d(in_ch, out_ch, 1, stride)

    def forward(self, x):
        res = self.shortcut(x)
        out = F.relu(self.conv1(x))
        out = F.relu(self.conv2(out))
        out = self.conv3(out)
        return F.relu(out + res)
```

```python
class HDImageClassifier(nn.Module):
    def __init__(self, num_classes=3, pretrained=True):
        super().__init__()
        self.backbone = torchvision.models.resnet50(weights="DEFAULT" if pretrained else None)
        in_features = self.backbone.fc.in_features  # 2048
        self.backbone.fc = nn.Sequential(
            nn.Linear(in_features, 512),
            nn.ReLU(inplace=True),
            nn.Dropout(p=0.3),
            nn.Linear(512, num_classes)
        )
    def forward(self, x):
        return self.backbone(x)  # [B, 3] logits
```

3. BIDIRECTIONAL LSTM (LONGITUDINAL CLINICAL ENCODER)
--------------------------------------------------------------------------------
• WHERE USED: neurosense/models/clinical_encoder.py
• LOGIC: 2-layer Bi-LSTM encodes sequential clinical visits [B, T, 5] (CAG, motor,
  cognitive, daily function, age), concatenating forward and backward trajectories.

• CODE SNIPPET:
```python
class ClinicalEncoder(nn.Module):
    def __init__(self, input_dim=5, hidden_dim=256, embed_dim=256):
        super().__init__()
        self.lstm = nn.LSTM(input_dim, hidden_dim, num_layers=2,
                            batch_first=True, bidirectional=True, dropout=0.3)
        self.proj = nn.Sequential(
            nn.Linear(hidden_dim * 2, embed_dim),  # 512 -> 256
            nn.ReLU(),
            nn.LayerNorm(embed_dim)
        )
    def forward(self, x, lengths):
        packed = nn.utils.rnn.pack_padded_sequence(x, lengths.cpu(), batch_first=True, enforce_sorted=False)
        _, (h_n, _) = self.lstm(packed)
        cat_h = torch.cat([h_n[-2], h_n[-1]], dim=-1)  # [B, 512]
        return self.proj(cat_h)                         # [B, 256]
```

4. CROSS-MODAL MULTI-HEAD ATTENTION FUSION
--------------------------------------------------------------------------------
• WHERE USED: neurosense/models/fusion.py
• LOGIC: Visual Query (MRI) attends to Key/Value of Clinical features; cross-modal
  representations are fused through LayerNorm, residual additions, and a feedforward block.

• CODE SNIPPET:
```python
class CrossModalFusion(nn.Module):
    def __init__(self, embed_dim=256, num_heads=8):
        super().__init__()
        self.cross_attn = nn.MultiheadAttention(embed_dim, num_heads, batch_first=True)
        self.norm1 = nn.LayerNorm(embed_dim)
        self.ffn = nn.Sequential(nn.Linear(embed_dim, 1024), nn.GELU(), nn.Linear(1024, embed_dim))
        self.norm2 = nn.LayerNorm(embed_dim)

    def forward(self, img_emb, clin_emb):
        # Q = MRI, K & V = Clinical
        q, kv = img_emb.unsqueeze(1), clin_emb.unsqueeze(1)
        attn_out, _ = self.cross_attn(query=q, key=kv, value=kv)
        x = self.norm1(q + attn_out)
        out = self.norm2(x + self.ffn(x))
        return out.squeeze(1)  # [B, 256] joint embedding
```

5. GRADCAM++ (EXPLAINABLE AI ACTIVATION HEATMAPS)
--------------------------------------------------------------------------------
• WHERE USED: neurosense/explainability/gradcam.py
• LOGIC: Computes 2nd and 3rd order gradients to weight feature map activations,
  generating spatial heatmaps that pinpoint striatal neurodegeneration.

• CODE SNIPPET:
```python
def compute_gradcam_weights(gradients, activations):
    # gradients: [B, C, D, H, W], activations: [B, C, D, H, W]
    g2 = gradients.pow(2)
    g3 = gradients.pow(3)
    sum_acts = activations.sum(dim=(2, 3, 4), keepdim=True)
    denom = 2 * g2 + sum_acts * g3
    denom = torch.where(denom != 0.0, denom, torch.ones_like(denom))
    aij = g2 / denom
    alpha = (aij * F.relu(gradients)).sum(dim=(2, 3, 4), keepdim=True)
    heatmap = F.relu((alpha * activations).sum(dim=1, keepdim=True))
    return heatmap  # [B, 1, D, H, W]
```

--------------------------------------------------------------------------------
• WHERE USED: neurosense/explainability/shap_analysis.py

  clinical biomarker (CAG, Motor, Cognitive, Function, Age) on the prediction.

• CODE SNIPPET:

```python
import shap

def explain_clinical_sample(model, background_tensor, sample_tensor):
    explainer = shap.DeepExplainer(model, background_tensor)
    shap_values = explainer.shap_values(sample_tensor)  # [classes, features]
    feature_attributions = {
        feat_name: float(val)
        for feat_name, val in zip(["CAG", "Motor", "Memory", "Function", "Age"], shap_values[0])
    }
    return feature_attributions
```

7. MULTI-TASK PROGRESSION FORECASTING HEAD
--------------------------------------------------------------------------------
• WHERE USED: neurosense/models/classifier.py
• LOGIC: Dual-headed output: categorical classification (Pre-manifest, Early, Advanced)
  alongside continuous regression predicting 12-month and 24-month progression delta.

• CODE SNIPPET:
```python
class MultiTaskHead(nn.Module):
    def __init__(self, embed_dim=256, num_classes=3):
        super().__init__()
        self.classifier = nn.Linear(embed_dim, num_classes)       # Staging
        self.progression = nn.Linear(embed_dim, 2)               # [12-mo Δ, 24-mo Δ]

    def forward(self, fused_emb):
        logits = self.classifier(fused_emb)
        deltas = self.progression(fused_emb)
        probs = F.softmax(logits, dim=-1)
        return {"logits": logits, "probs": probs, "deltas": deltas}
```

8. ADAPTIVE CLINICAL SCORING & LANGBEHN MOTOR ONSET ENGINE
--------------------------------------------------------------------------------
• WHERE USED: neurosense/api/clinical_scoring.py
• LOGIC: Empirical parametric formula (Langbehn et al.) calculates estimated years
  to motor onset based on CAG repeat length and patient age.

• CODE SNIPPET:
```python
def langbehn_onset_estimation(cag_repeat: float, age: float) -> float:
    if cag_repeat < 36:
        return 50.0  # Normal non-expanded allele
    # Median motor onset equation:
    median_onset = 21.54 + math.exp(9.556 - 0.146 * cag_repeat)
    median_onset = max(15.0, min(90.0, median_onset))
    years_to_onset = median_onset - age
    return years_to_onset  # Positive = pre-manifest years remaining
```

10. OPTIMIZATION & LOSS FUNCTION PIPELINE
--------------------------------------------------------------------------------
• WHERE USED: neurosense/training/trainer.py, neurosense/models/loss.py
• LOGIC: Combines Cross-Entropy/Focal Loss with Multi-Task Huber Regression Loss
  and Cosine Annealing with Warm Restarts.

• CODE SNIPPET:
```python
class CompositeLoss(nn.Module):
    def __init__(self, lambda_prog=0.5):
        super().__init__()
        self.cls_loss = nn.CrossEntropyLoss()
        self.reg_loss = nn.SmoothL1Loss()  # Huber loss
        self.lambda_prog = lambda_prog

    def forward(self, logits, targets, pred_deltas, target_deltas):
        loss_cls = self.cls_loss(logits, targets)
        loss_reg = self.reg_loss(pred_deltas, target_deltas)
        return loss_cls + self.lambda_prog * loss_reg
```
